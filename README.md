# 책 분석 + 거짓말 사냥

아동·청소년이 비문학 책을 읽고, 내용을 암기하는 대신 **자기 삶과 연결해 이해하고
남에게 설명할 수 있게** 만드는 AI 독해 교육 도구.

책 본문을 붙여넣으면 두 가지가 만들어진다.

1. **세포 이야기를 뼈대로 삼은 내용 분석** — 챕터 하나를 담을 세포 장면을 먼저 정하고,
   모든 설명이 그 장면으로 계속 돌아온다.
2. **거짓말 사냥 활동** — 요약문 8~10개 중 3개에 거짓말을 심고, 학생이 찾아낸다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `book_analysis_app.html` | 메인 웹 앱. 이 파일 하나로 전체 기능이 작동한다. |
| `Code.gs` | Google Apps Script 중계 서버. Gemini API 키를 서버에 숨긴다. |
| `lie_types.json` | **거짓말 유형 원본.** 여기만 고치고 build.py·make_docx.py를 돌리면 앱·웹·워드가 함께 바뀐다 |
| `build.py` / `make_docx.py` | 원본에서 앱·웹페이지·워드를 생성 |
| `거짓말 12종 도감.docx` | 학생·멘토에게 나눠 줄 인쇄용 도감 |
| `web/거짓말-도감.html` | 폰으로 읽는 웹 도감 |
| `docs/거짓말-유형-체계.md` | 분류 체계, 12종 목록, 출제 규칙 |
| `docs/세포-중심-구조.md` | 세포 비유를 뼈대로 삼는 설명 구조 |

## 시작하기

연결 방법이 두 가지다. 화면 맨 위 연결 패널에서 고른다.

### 방법 A — 혼자 쓸 때 (설치할 게 없다)

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 Gemini API 키 발급 (무료)
2. `book_analysis_app.html`을 브라우저로 연다
3. 연결 패널에 키를 붙여넣고 **연결 테스트**를 누른다

키는 그 브라우저에만 저장되고 다른 곳으로 나가지 않는다. 파일을 남에게 줘도
키는 따라가지 않으므로, 공유하려면 방법 B를 쓴다.

### 방법 B — 남에게 나눠 줄 때

1. [script.google.com](https://script.google.com)에서 새 프로젝트를 만들고 `Code.gs`를 붙여넣기
2. `GEMINI_API_KEY`에 키 입력
3. **배포 → 새 배포 → 웹 앱 → 액세스: 모든 사용자** → `/exec`로 끝나는 URL 복사
4. 연결 패널에서 "중계 서버 쓰기"를 고르고 그 URL을 붙여넣기
5. [netlify.com/drop](https://app.netlify.com/drop)에 HTML 파일을 끌어다 놓고, 생성된 `https://` 주소를 공유

받는 사람은 키가 필요 없다. 다만 로컬 파일을 그냥 열면 브라우저가 외부 호출을
막으므로, 5단계처럼 HTTPS로 호스팅해야 한다. (방법 A는 로컬에서도 작동한다.)

## 구조

```
입력 (책 제목 / 챕터 / 핵심 개념 / 본문)
   ↓
호출 1  세포 앵커 확정 + 배경지식      → ⓪ 앵커 카드, ① 배경지식
호출 2  욕구·행동                     → ② 욕구와 행동
호출 3  챕터 연결 + 전체 다시 보기      → ③ 챕터 연결, ④ 마무리
호출 4  거짓말 사냥                    → ⑤ 요약 · 힌트 · 정답
```

분석을 네 번으로 나눈 것은 한 번에 요청하면 토큰 한도를 넘고 품질이 떨어지기 때문이다.

## 개발 메모

거짓말 유형은 `lie_types.json` **하나만** 고친다. 그다음:

```
python build.py      # 앱 사이드바 + AI 프롬프트 + 웹 페이지
python make_docx.py  # 인쇄용 워드
```

앱 안의 `LIE_DATA` 블록은 build.py가 생성하므로 직접 고치지 마라.
사이드바 도감과 AI 프롬프트가 같은 데이터에서 나오므로, 화면에 보이는 정의와
모델이 받는 정의가 어긋날 수 없다.

세포 중심 설명 규칙은 `PROSE_RULES` 상수 하나에 모여 있고, 세 번의 분석 호출이 모두
이것을 공유한다.
