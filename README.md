# 책 분석 + 거짓말 사냥

아동·청소년이 비문학 책을 읽고, 내용을 암기하는 대신 **자기 삶과 연결해 이해하고
남에게 설명할 수 있게** 만드는 AI 독해 교육 도구.

책 본문을 붙여넣으면 두 가지가 만들어진다.

1. **세포 이야기를 뼈대로 삼은 내용 분석** — 챕터 하나를 담을 세포 장면을 먼저 정하고,
   모든 설명이 그 장면으로 계속 돌아온다.
2. **거짓말 사냥 활동** — 요약문 8~10개 중 3개에 거짓말을 심고, 학생이 찾아낸다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `book_analysis_app.html` | 메인 웹 앱. 이 파일 하나로 전체 기능이 작동한다. |
| `Code.gs` | Google Apps Script 중계 서버. Gemini API 키를 서버에 숨긴다. |
| `거짓말 10종 도감.docx` | 학생·멘토에게 나눠 줄 인쇄용 도감 |
| `docs/거짓말-유형-체계.md` | 거짓말 분류 체계와 출제 규칙 |
| `docs/세포-중심-구조.md` | 세포 비유를 뼈대로 삼는 설명 구조 |

## 설치

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 Gemini API 키 발급 (무료)
2. [script.google.com](https://script.google.com)에서 새 프로젝트를 만들고 `Code.gs` 내용을 붙여넣기
3. `GEMINI_API_KEY`에 발급받은 키 입력
4. **배포 → 새 배포 → 웹 앱 → 액세스: 모든 사용자** → 배포 URL 복사
5. `book_analysis_app.html`의 `GAS_URL`에 그 URL 붙여넣기
6. [netlify.com/drop](https://app.netlify.com/drop)에 HTML 파일을 끌어다 놓고, 생성된 `https://` 주소를 공유

> 로컬에서 HTML을 직접 열면 브라우저 CORS 정책 때문에 외부 호출이 막힌다.
> 반드시 5~6단계처럼 HTTPS로 호스팅해서 써야 한다.

한 번 설정해 두면 이후에는 HTML 파일만 공유하면 된다. 받는 사람에게는 API 키가 필요 없다.

## 구조

```
입력 (책 제목 / 챕터 / 핵심 개념 / 본문)
   ↓
호출 1  세포 앵커 확정 + 배경지식      → ⓪ 앵커 카드, ① 배경지식
호출 2  욕구·행동                     → ② 욕구와 행동
호출 3  챕터 연결 + 전체 다시 보기      → ③ 챕터 연결, ④ 마무리
호출 4  거짓말 사냥                    → ⑤ 요약 · 힌트 · 정답
```

분석을 네 번으로 나눈 것은 한 번에 요청하면 토큰 한도를 넘고 품질이 떨어지기 때문이다.

## 개발 메모

거짓말 유형 정의는 `book_analysis_app.html` 안의 `LIE_FAMILIES` **하나만** 고치면 된다.
사이드바 도감과 AI 프롬프트가 같은 배열에서 나오므로, 화면에 보이는 정의와 모델이 받는
정의가 어긋날 수 없다.

세포 중심 설명 규칙은 `PROSE_RULES` 상수 하나에 모여 있고, 세 번의 분석 호출이 모두
이것을 공유한다.
