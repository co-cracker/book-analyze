# 세포 이야기를 뼈대로 삼는 구조

책 본문을 넣었을 때 "내용 이해" 부분이 어색했던 문제를 고친 기록이다.

---

## 1. 무엇이 어색했나

이전 구조는 이랬다.

```
① 배경지식      책 구절 인용 → 쉬운 말로 풀어 설명
② 욕구와 행동    책 구절 인용 → 쉬운 말로 풀어 설명
③ 챕터 연결      책 구절 인용 → 쉬운 말로 풀어 설명
④ 세포 비유      ← 세포가 여기서 딱 한 번, 맨 끝에만 나온다
```

문제는 두 가지였다.

**하나. 인용하고 같은 말을 반복했다.** 책 문장을 따온 다음 "즉, 이는 ~라는 뜻이다"로
같은 내용을 쉬운 단어로 바꿔 쓰는 것이 설명의 전부였다. 단어만 쉬워졌을 뿐 아이가
붙잡을 새로운 그림이 없다. 읽고 나면 남는 것이 없다.

**둘. 세포 비유가 장식이었다.** 맨 마지막에 한 번 등장하고 끝나니, 앞의 설명과
아무 관계가 없다. 비유는 반복해서 돌아올 때 이해의 틀이 되는데, 한 번 쓰고 버리면
그냥 재미있는 딴 이야기다.

## 2. 어떻게 바꿨나 — 세포를 맨 앞으로, 그리고 계속 돌아오기

```
⓪ 세포 앵커     이 챕터를 담을 세포 장면 하나를 먼저 정한다 (네 박자 + 대응표)
① 배경지식      🔬 세포로 돌아오기 1번째
② 욕구와 행동    🔬 세포로 돌아오기 2번째
③ 챕터 연결      🔬 세포로 돌아오기 3번째
④ 전체 다시 보기  세 번의 회귀를 하나의 이야기로 이어 붙인다
```

### 앵커 — 네 박자로 고정한다

첫 번째 호출에서 세포 장면을 하나만 정하고, 이후 모든 설명이 그 장면으로만 돌아온다.
장면은 네 박자로 고정된다.

| 박자 | 예시 (에니어그램 4번 유형) |
| --- | --- |
| 평소 하는 일 | 대식세포가 침입자를 혼자 삼켜 없앤다 |
| 혼자서는 안 되는 순간 | 침입자가 너무 많아 다 삼킬 수 없게 된다 |
| 보내는 신호 | 사이토카인을 뿜어 도움을 청한다 |
| 불려오는 도우미 | T세포가 달려와 함께 싸운다 |

여기에 **세포 ↔ 책 대응표**를 4~5쌍 붙인다. 대식세포 = 4번 유형, 혼자 삼키다 지치는
순간 = 채워지지 않는 결핍감, 이런 식이다. 이 표가 화면 맨 위에 계속 떠 있어서
아이가 언제든 대조할 수 있다.

앵커는 이후 모든 프롬프트에 `anchorBlock()`으로 통째로 실려 들어간다. 그래서 2번,
3번 호출이 새 세포를 데려오지 못한다.

### 단락 뼈대 — 세 박자를 강제한다

모든 분석 단락은 `PROSE_RULES`가 정한 순서를 지킨다.

1. **세포 장면에서 시작한다.** 앵커의 네 박자 중 어느 대목인지 짚으며 연다.
2. **그 대목과 같은 구조인 책 구절을 인용한다.**
3. **다시 세포로 돌아와 한 걸음 나아간다.** "그래서 그 세포는 이제 무엇을 하는가"까지 쓴다.

3번이 핵심이다. 인용에서 끝내면 다시 "인용 후 풀이"가 되어 버린다. 세포로 돌아와야
비유가 한 바퀴 돌고, 다음 단락이 이어받을 자리가 생긴다.

### 반복 설명을 막는 금지 목록

프롬프트에 그대로 들어가는 금지 항목이다.

- 책 문장을 인용한 뒤 같은 뜻을 쉬운 단어로 바꿔 다시 쓰는 것
- "즉", "다시 말해", "이는 ~라는 뜻이다", "정리하면"으로 시작하는 문장
- 세포 이야기 없이 책 내용만 이어 쓰는 단락
- 앵커에 없던 새 세포를 데려오는 것

두 번째 항목이 실질적인 장치다. 반복 설명은 거의 항상 이 접속어로 시작하기 때문에,
이것만 막아도 모델이 다른 방식으로 설명을 이어 갈 수밖에 없다.

## 3. 화면에서 보이는 것

- 결과 맨 위에 **세포 앵커 카드**(어두운 배경)가 붙는다. 네 박자와 대응표가 한눈에 들어온다.
- ①②③ 각 섹션 제목 옆에 **🔬 세포로 돌아오기 N번째** 표시가 붙어, 반복이 눈에 보인다.
- 본문 표기는 세 가지다. `[[책 구절]]`은 어두운 인용 블록, `{{세포말}}`은 청록 강조,
  `**개념어**`는 보라 강조. 세포 이야기와 책 개념이 색으로 구분돼 섞이지 않는다.

## 4. 호출 구조 (개정)

가이드가 정한 4파트 순서를 그대로 따른다. 세포 비유가 ①이다.

| 호출 | 파트 | 반환 |
| --- | --- | --- |
| 1 | ① 세포·면역계 비유 | `core_line` `need_no` `need_name` `cell_name` `pick_reason` `step1`~`step4` `cell_job` `cell_crisis` `cell_signal` `cell_helper` `map` |
| 2 | ② 배경지식 설명 | `prose` |
| 3 | ③ 욕구와 행동 유형 | `desire_name` `behavior_type` `direction` `prose` `scenes[3]` |
| 4 | ④ 챕터 연결 필연성 | `prose` `link_type` `scenes[2]` |
| 5 | ⑤ 거짓말 사냥 | `sentences` `lies` |

①의 4단계는 각 2문장 이상이고, 1단계에는 "이 세포는 마치 ○○처럼 작동해"와
전문 용어 괄호 설명이, 4단계에는 "이것이 바로 이 챕터가 말하는 ○○이다"가
반드시 들어간다. ③과 ④의 `scenes`는 상황 → 내면 반응 → 결과 세 칸이다.

모든 호출이 같은 역할 문장과 같은 금지 사항(`ROLE`, `BAN`, `CELL_BAN`)을
쓴다. 같은 책을 넣으면 같은 구조가 나오도록 온도는 0.15로 낮췄고,
Gemini는 확장 사고(`thinkingLevel: high`)로 붙는다.

거짓말 사냥에도 앵커가 함께 전달되고, 요약 문장 중 2~3개는 세포 이야기를 빌려 쓴
문장으로 만들도록 했다. 세포 이야기도 검증 대상이 되어야 아이가 비유를 외운 대로
믿지 않는다.
